## Category legend

- **Zero-width character** (`high`): Invisible character that hides or alters code semantics.
- **Bidirectional override** (`critical`): Direction control that can reorder how text is displayed (classic 'Trojan Source' attack).
- **Unbalanced bidi control** (`critical`): A bidirectional embedding/isolate was opened but never closed.
- **Homoglyph / confusable** (`high`): A character that visually resembles an ASCII letter but is a different code point.
- **Fullwidth / compatibility form** (`medium`): Fullwidth or compatibility-form character; often a confusable of ASCII.
- **Suspicious whitespace** (`medium`): Looks like a space but is a different whitespace code point.
- **Control character** (`high`): Non-printable control character embedded in source.
- **Unicode noncharacter** (`medium`): Permanently reserved non-character code point.
- **Mixed-script token** (`high`): Identifier mixing ASCII with a non-ASCII script (e.g. Cyrillic).
- **Compatibility masquerade** (`medium`): Character whose compatibility (NFKC) form is a single ASCII character; often used to spoof identifiers.
